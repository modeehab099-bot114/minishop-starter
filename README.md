# MiniShop — STUDENT STARTER (not completed)

This is the **starter project** for the 3-hour React workshop. It contains **no finished shop features**.

## Run it

```bash
npm install
npm run dev
```

## Already included
- Vite + React
- Bootstrap imported
- React Router package installed (not configured yet)
- Simple welcome page
- Empty `src/components`, `src/pages`, and `src/context` folders

## Build with your instructor
1. Create `components/ProductCard.jsx` and learn Props.
2. Display sample products with `.map()`.
3. Fetch products from `https://dummyjson.com/products?limit=12` with `useState` and `useEffect`.
4. Add a search form using `https://dummyjson.com/products/search?q=phone`.
5. Add React Router and create Products, ProductDetails and Cart pages.
6. Create `context/CartContext.jsx`, connect Add to Cart, and implement quantities.
7. Add cart persistence with localStorage.

There are deliberately no finished ProductCard, Products, ProductDetails, Cart, Navbar or CartContext implementations in this ZIP. You will write them during the workshop.
